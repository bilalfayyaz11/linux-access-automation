# Linux Access Automation

Enterprise-focused infrastructure automation portfolio demonstrating Linux administration, access management, security enforcement, configuration validation, service orchestration, and Ansible-driven operations.

## Overview

This repository contains automation implementations focused on Linux systems administration and infrastructure operations. The projects emphasize repeatable, idempotent, and secure automation practices commonly used by DevOps Engineers, Platform Engineers, Systems Administrators, Infrastructure Engineers, and Site Reliability Engineers.

The work demonstrates practical experience with:

* Linux administration
* Ansible automation
* User and access management
* Service lifecycle management
* Firewall administration
* SELinux policy management
* Configuration validation
* Secrets management
* Multi-environment deployments
* Troubleshooting and operational diagnostics
